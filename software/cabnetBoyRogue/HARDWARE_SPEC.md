# cabnetBoy v2 — PCB 설계 입력 사양서

새로 만드는 보드가 **이번엔 첫 굽기부터 게임이 돌아가도록** 하기 위한 요구사항입니다.
"이렇게 하면 펌웨어가 이렇게 동작한다" 기준으로 썼습니다. 앞선 리뷰에서 실제로
문제가 됐던 항목은 `⚠️` 로 표시했습니다.

---

## 1. 결정 사항 (확정)

| # | 항목 | 결정 | 결과 |
|---|---|---|---|
| A | 방향 버튼 | **개별 4핀** (래더 폐기) | ADC 채널 공유·캘리브레이션·DOWN 인식 문제 소멸, RIGHT 버튼 생김 |
| B | 회전 입력 | **EC11 로타리 엔코더** (포텐셔미터 폐기) | 무한 회전 + 디텐트 클릭, ADC 불필요, 자동 보정 불필요 |
| C | 셀렉트 버튼 | **엔코더 누름 스위치** 사용 | 버튼 6개 = 4방향 + ACT + SEL(엔코더 누름). 핀 1개 절약 |

> 엔코더를 쓰지 않게 되면 RV09 **B형(선형)** 을 PD4(ADC7)에 그대로 쓸 수 있습니다.
> A형(로그) 테이퍼는 절대 금지 — 섹터 간격이 무너집니다.

## 2. 확정 핀맵 (CH32V003A4M6 SOP16) — 자가진단 펌웨어와 동일

| 핀 | 이름 | 기능 | 비고 |
|---|---|---|---|
| 1 | PC1 | I2C SDA | OLED. **4.7k 풀업 필수** |
| 2 | PC2 | I2C SCL | OLED. **4.7k 풀업 필수** |
| 3 | PC3 | BTN_UP | 택트 → GND, 내부 풀업 |
| 4 | PC4 | BTN_DOWN | 택트 → GND |
| 5 | PC6 | BTN_LEFT | 택트 → GND |
| 6 | PC7 | BTN_RIGHT | 택트 → GND |
| 7 | PD1 | DIO / SWIO | **프로그래밍 필수.** 3핀 헤더, 부하 금지 |
| 8 | PD4 | ENC_A | EC11 A상 (+100nF → GND) |
| 9 | PD5 | ENC_B | EC11 B상 (+100nF → GND) |
| 10 | PD6 | SLIDER | U5 B10K **와이퍼** (ADC6) + 100nF → GND |
| 11 | PD7 | NRST | **리셋 택트 + 100nF → GND** |
| 12 | PA1 | ENC_SW | 엔코더 누름 = SELECT. 택트 → GND |
| 13 | PA2 | BEEP | 1k → PNP 베이스, **10k 베이스-이미터 풀업 추가** |
| 14 | VSS | GND | |
| 15 | VDD | VCC | |
| 16 | PC0 | BTN_ACT | 택트 → GND |

**14 GPIO 전부 사용.** 이 표는 `software/cabnetBoyTest/src/hw.h` 와 1:1로 일치합니다.

### EC11 배선
```
        VCC (내부 풀업 사용 시 불필요)
  A ──┬── PD4        A ── 100nF ── GND
      └── 100nF ── GND
  B ──┬── PD5        B ── 100nF ── GND
      └── 100nF ── GND
 COM ── GND
 SW  ── PA1,  SW 반대쪽 ── GND
```
- 디텐트당 펄스 수는 제품마다 다릅니다. `hw.h` 의 `ENC_DIV` (기본 4)로 맞춥니다.
  자가진단 화면에서 한 클릭에 2씩 움직이면 2로 바꾸면 됩니다.

### 이 핀맵이 주는 것
- **4방향 직접 이동** (지금 보드는 RIGHT 버튼이 없어 회전+전진으로 우회 중)
- ADC를 **슬라이더 1채널만** 사용 → 채널 전환/공유 버그 원천 차단
- 버튼에 캘리브레이션·임계값 불필요 → DOWN이 안 먹던 문제 재발 불가
- 6버튼이라 무기 셀렉트 전용 입력 확보

## 3. ⚠️ 아날로그 입력 배선 규칙 (이번엔 꼭)

### 3-1. 포텐셔미터는 "양끝 = VCC/GND, 와이퍼 = ADC"
```
        VCC
         │
      [ 트랙 ]  ← 포텐셔미터 저항체
         │
   끝 ───┼─── 끝
   │          │
  GND      (사용 안 함)
         │
      와이퍼 ──┬── ADC 핀
              ├── 100nF → GND   (노이즈 필터)
              └── (선택) 1k 직렬
```
**현 보드의 실패 원인**: VCC가 **와이퍼**에, ADC가 **트랙 끝**에 붙어 있었습니다.
트랙 끝은 전류가 흐르지 않아 ADC가 항상 VCC를 읽습니다. 게다가 와이퍼가 GND 끝에
닿으면 **VCC–GND 단락**이 됩니다. (PCB 동박에서 실제 확인: `U5.1=GND`, `U5.2=VCC`,
`U5.3=R_Slider`)

### 3-2. ADC 기준전압은 VDD 그대로
- 포텐셔미터도 VCC로 구동하므로 **비율식(ratiometric)** → 배터리가 떨어져도 값이 안 변합니다.
- 내부 1.2V 레퍼런스는 쓰지 마세요 (코드도 안 씁니다).

### 3-3. ADC 소스 임피던스
- 10k 포텐셔미터는 소스 임피던스가 최대 2.5k입니다 (펌웨어가 `ADC_slow()`로 긴 샘플링 사용).
- 슬라이더가 100k 이상이면 **버퍼(op-amp) 또는 1k+100nF RC**를 꼭 넣으세요.

### 3-4. 슬라이더(U5) 풋프린트 주의
- 현 보드의 U5는 **SMD 슬라이드 포텐셔미터, 패드 4개**(1번 2개 + 2·3번 각 1개)에
  **NPTH 슬롯 2개**(1.40 mm, 장홀 2.8 mm)로 고정됩니다.
- 같은 부품을 쓴다면 **패드 번호와 네트를 반드시 대조**하세요:
  `1 = GND`, `2(와이퍼) = ADC`, `3 = VCC`.
- NPTH 슬롯은 CAM에서 **G85 슬롯**으로 나갑니다. 발주 시 "슬롯 포함"을 명시하세요.

## 4. ⚠️ 지난 보드에서 반드시 고쳐야 할 것

| 항목 | 지난 보드 상태 | v2 요구사항 |
|---|---|---|
| U5 슬라이더 | 와이퍼에 VCC, ADC에 트랙 끝 → **동작 불가 + 단락 위험** | 와이퍼 → ADC, 양끝 → VCC/GND |
| EEPROM WP(7) | **플로팅** (No-Connect) | **GND로 연결** (세이브 기능 쓰려면 필수) |
| 드릴 파일 | 숫자 포맷이 주석에만, G85 슬롯 3개가 이동 2µm, Via 드릴 중복 | 포맷 명시, 슬롯 정리, **PTH 드릴 1개만** |
| 실크-패드 겹침 | 상 1.97 mm², 하 6.69 mm² | 실크를 패드 밖으로 (DRC 켜기) |
| 최소 동박 간격 | 하단 **0.122 mm** | Pour Clearance ≥ 0.15 mm |
| 동박-기판 외곽 | **0.128 mm** | ≥ 0.2 mm |
| 보드 외곽선 | 0.254 mm 굵은 선, 상단이 2조각으로 분리 | 닫힌 단일 폴리곤, 0.1 mm 선 |
| 부저 베이스 | 1k만 있음 | **10k 베이스-이미터 풀업 추가** (리셋 중 오동작 방지) |
| 리셋 | 없음 | **NRST 택트 + 100nF** |
| I2C | R2/R3 4.7k 있음 ✅ | 유지 |
| 디커플링 | C1 100nF + C2 10uF ✅ | VDD 근처에 100nF, 벌크 10uF 유지 |

### 추가로 넣으면 좋은 것
- **테스트 포인트**: VCC, GND, PD1(SWIO), PD6(슬라이더), PD4/PA1(엔코더)
- **전원 스위치** 접점에 100nF (채터링)
- OLED 커넥터 옆에 **핀1 마킹** (지금은 실크로만 표시)
- 배터리 전압을 ADC로 감시하려면 VCC를 100k/100k로 분압해 예비 ADC핀에 (배터리 잔량 표시용)

## 5. 전원 / 배터리 (설계 검토 권장)

- CR2032(3.0 V)로 **SSD1306 + 부저**를 함께 돌리면 순간 20~30 mA가 필요합니다.
  CR2032 내부저항이 10~40 Ω이라 **전압 강하가 큽니다** (OLED가 어두워지거나 리셋).
- 선택지:
  1. **LIR2032** (3.6 V 충전지) — 같은 풋프린트, 전압/전류 여유 ↑
  2. **AAA 2셀 (3.0 V)** — 용량/전류 여유 큼, 보드가 커짐
  3. **LiPo + 3.3 V LDO** — 가장 안정적, 충전 회로 필요
- OLED 백라이트가 없어 소비는 대부분 OLED 차지펌프 + 부저입니다. 부저를 PWM으로
  짧게만 울리는 것도 방법입니다 (펌웨어에서 조정 가능).

## 6. 펌웨어가 준비돼 있는 부분 / 새로 할 일

**그대로 동작 (핀맵만 맞추면):**
- `retro.c` 보드 계층 — 핀 정의만 바꾸면 됩니다 (`PIN_ACT`, `PIN_PAD`, `PIN_SLIDER`, `PIN_ROTATE`)
- 렌더러·폰트·던전 생성·전투·마법 (전부 핀 독립)

**핀맵 확정 후 할 일:**
1. `retro.h` 핀 재정의 + 4방향 버튼 직접 읽기 (`retro_buttons()` 확장)
2. 엔코더를 쓰면 `retro.c`에 2상 상태머신 + 디텐트 디바운스 추가
3. 게임 입력 매핑 변경:
   - 4방향 버튼 = 이동/공격 (회전+전진 방식 제거)
   - SEL = 무기 셀렉트, ACT = 공격/사용
   - 슬라이더 = 파워/마법 세기 (그대로)
   - 엔코더/노브 = 마법 조준 (이동과 분리)
4. **부팅 자가진단**: OLED에 각 입력 원시값 표시 (아래)

### 자가진단 펌웨어 ✅ (만들었습니다)
`software/cabnetBoyTest/` — 새 보드 첫 굽기용. 버튼 6개, 엔코더 디텐트/AB상, 슬라이더
원시값+바, VDD(mV), 슬라이더 MIN/MAX 를 한 화면에 표시하고 아래를 자동 판정합니다:

```
SLIDER RAIL HIGH   <- VCC가 와이퍼에 붙은 배선 (구보드의 실제 증상)
SLIDER RAIL LOW!   <- 트랙 한쪽 GND 단락
SLIDER OK / MOVE THE SLIDER
OLED NOT FOUND!    <- I2C NACK/타임아웃 (이때는 부저로 3번 울려 알림)
BTN STUCK AT BOOT  <- 부팅 시 눌린 버튼이 계속 눌림
LOW BATTERY        <- VDD < 2.7V
```

빌드 검증 완료: **Flash 3880 B (23.7%) / RAM 296 B (14.5%), 경고 0.**
자세한 사용법은 `software/cabnetBoyTest/README.md` 참조.
